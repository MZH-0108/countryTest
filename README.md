# 上岸计划

国考、省考和事业编备考网站。纯静态页面，可部署到 GitHub Pages，支持手机和电脑使用及离线缓存。

## 功能

- 按阶段和每周时间生成每日任务
- 原创行测/职测练习题（练习和限时模式）
- 错题本（按 1、3、7 天间隔复习）
- 申论、综应、面试写作，并生成 AI 批改指令
- 模块正确率、错因和做题量统计
- 录入外部平台成绩和自己的题目
- 同步进度到私有 GitHub 仓库

## 部署

1. 把本目录的文件推送到仓库的 `main` 分支。
2. 打开仓库 Settings → Pages，来源选择 `Deploy from a branch`，分支选 `main`，目录选 `/(root)`。
3. 免费账号要求代码仓库为公开仓库。这里只放网站代码和题库，个人进度放在下面的私有数据仓库。

## 设置同步

1. 新建一个私有仓库，例如 `countryTest-data`。
2. 在 GitHub 创建 Fine-grained token：只选择这个数据仓库，权限 `Contents` 设为 Read and write。
3. 在网站“设置”中填写用户名、仓库名和令牌。手机和电脑各填一次。

令牌只保存在当前浏览器。不要在公共电脑上填写，也不要把它提交到仓库。

## 更新题库

修改 `data/` 下的文件后，同步修改 `sw.js` 里的 `CACHE` 版本号，否则已安装的设备可能继续使用旧缓存。

题目和材料均为原创练习内容，数据为虚构，不代表真实考试。考试日期为预估，以官方公告为准。
